# 回測程式（2026-10-12）

在這個資料夾執行。下載的資料（*.json、*.pkl）不進版控，第一次先抓：

```
python fetch.py    # 台積電、鴻海、玉山金
python fetch2.py   # 加權指數 TWII 與 0050、聯發科、中華電、富邦金
python fetch3.py   # 006208、0056、00878、00631L、00632R
python fetch4.py   # 22 檔 ETF
```

法人資料（inst.py 用 inst.json、oi*.py 用 txoi.json）由 FinMind 抓，程式開頭有網址，沒有檔案時先照 README 抓一次。

| 檔案 | 做什麼 |
|---|---|
| bt.py | 共用：讀 Yahoo、日線還原比例補除息、分割修正（超過漲跌幅上限）、Range Filter／Donchian 逐行照儀表板、績效 |
| mkt.py | 大盤濾網（加權趨勢決定持有個股） |
| etf.py | 加權指數模擬 0050／正 2，三段驗證（2009-17、2018-26、2000-08） |
| big.py / bigh.py / rank.py | 日線～5 日、60 分、2 小時全參數掃描與排名（bigh 已修 60 分 K 不含集合競價） |
| alletf.py / common.py / qc.py | 22 檔 ETF 抱著／看大盤／看自己 |
| inst.py | 三大法人現貨買賣超（無效） |
| oi.py / oi2.py / oi3.py | 外資台指期淨部位、平均線交叉、門檻 |

結論見儀表板「說明」面板與管理包注意事項。
